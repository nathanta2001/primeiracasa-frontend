# Minha Primeira Casa - PWA

Aplicação para auxiliar na organização de itens para uma nova residência.

## Tecnologias
- [cite_start]**Frontend**: React, TypeScript, Ant Design, React Router. [cite: 7, 8, 9]
- [cite_start]**Backend**: Java, Spring Boot, PostgreSQL (Supabase). [cite: 14]
- [cite_start]**PWA**: Service Workers, Web App Manifest, Push Notifications. [cite: 33, 38, 43]

## Como Executar
1. Instale as dependências: `npm install`
2. [cite_start]Inicie o backend (Spring Boot) na porta 8080. [cite: 14]
3. Execute o frontend: `npm run dev`
